# How to play
**Controls:** 
* mouse movement
* click

**Objective:** 
* Prepare coffe
* Serve customers
* **Be aware** at the start you can only make 4 coffe cups at a time and goes up to 6 with upgrades

**How to prepare coffe:** <img align = "right" width="448.5" height="246" alt="20260803-1749-03 5179592" src="https://github.com/user-attachments/assets/b6acedce-a685-4ee5-a22f-9f1d169865d7" />

* open the kitchen panel
* click the empty coffe cup
* fill the coffe cups with the coffe maker
* drag the full coffe cups to the box
* serve the coffe customers

# Game mechanics
* Brewing coffe using the coffe maker
* Serving customers
* Money system
* Max of 4 coffe cups you can have prepared at a time that can be increased using the upgrades 

# Content of the demo
* 1 type of drink
* 3 upgrades
   + Upgrade 1: Increases the coffe price by 2¥
   + Upgrade 2: decreases the time of customer arrival
   + Upgrade 3: Increases the number of coffes you can brew
* Customer serving
* Very cozy game loop
# How to launch
<img align = "right" width="450.5" height="450.5" alt="cozy" src="https://github.com/user-attachments/assets/595378b3-46c1-4722-87e6-127d8e60592e" />

If your playing the web version on itch just run on the browser via itch

If you're using the downloadable version for window:
* download the .zip file
* extract the game folder from the .zip
* assure that the files are all in the same folder
* run the unity file that has the name of the game
* **IMPORTANT**, don't run the unity crash handler
